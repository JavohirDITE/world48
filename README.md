# WORLD 48

Футбол по регламенту чемпионата мира 2026: 48 сборных, настоящие составы, VAR, правила IFAB, онлайн с друзьями.

**Играть:** https://javohirdite.github.io/world48/
**В Telegram:** https://t.me/world24kolos_bot

## На телефоне

- **Айфон:** открой ссылку в Safari → «Поделиться» → «На экран „Домой“». Игра откроется на весь экран и будет работать без интернета (онлайн-режимам интернет нужен).
- **Андроид:** открой ссылку в Chrome → меню → «Добавить на главный экран» (или поставь приложение APK).
- **Telegram:** открой бота и нажми «Играть».

Все версии играют вместе: комнаты, «Живой ЧМ» и «Быстрая игра» общие для приложения, браузера и Telegram.
Сервера у игры нет: сообщения шифруются и идут через публичные релеи, матч — напрямую между телефонами.

## Данные

Неофициальная фан-игра. Не связана с FIFA и национальными федерациями.

Составы, расписание и результаты — английская Википедия («2026 FIFA World Cup squads», «2026 FIFA World Cup»); регламент — Regulations for the FIFA World Cup 26 (редакция мая 2026); правила — IFAB Laws of the Game 2025/26 и изменения, объявленные для турнира; рейтинг — FIFA/Coca-Cola Men’s World Ranking от 11 июня 2026; флаги — flag-icons (MIT). Навыки игроков — модель на основе рейтинга сборной, позиции, числа матчей и голов за сборную и возраста.

Здесь лежит только собранная игра (`index.html`, иконки, манифест, офлайн-кэш).
